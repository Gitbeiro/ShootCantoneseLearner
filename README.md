# 粵語射擊學習 Cantonese Shooter Learning Game

An interactive 2D shooter game designed to help you learn Cantonese vocabulary through fun gameplay! Shoot enemies displaying Traditional Chinese characters while learning their pronunciation through Jyutping romanization and audio.

## Features

- **60+ Cantonese Words**: Learn vocabulary across multiple categories including greetings, numbers, colors, family, food, verbs, adjectives, and time expressions
- **Traditional Chinese Characters**: All words displayed in authentic Traditional Chinese
- **Jyutping Romanization**: Learn correct Cantonese pronunciation with Jyutping system
- **Audio Pronunciation**: Click on words to hear them pronounced using Text-to-Speech
- **Progressive Difficulty**: Game gets harder as you advance through levels
- **Score & Statistics**: Track your score and how many unique words you've learned

## How to Play

### Controls
- **← → Arrow Keys**: Move your spaceship left and right
- **Spacebar**: Shoot bullets
- **Click on word display**: Hear the pronunciation of the current word

### Game Rules
1. Enemies with Chinese characters will descend from the top of the screen
2. Shoot the enemies before they reach the bottom
3. When you hit an enemy, you'll learn that word with its pronunciation
4. You start with 3 lives
5. Lose a life when an enemy reaches the bottom
6. Gain points for each enemy destroyed
7. Level up every 100 points
8. Game ends when you lose all lives

## Getting Started

1. Open `index.html` in a modern web browser (Chrome, Firefox, Safari, or Edge recommended)
2. Click "Start Game" to begin
3. Use arrow keys to move and spacebar to shoot
4. Learn Cantonese while having fun!

## Vocabulary Categories

The game includes words from these categories:
- **Greetings**: 你好 (hello), 多謝 (thank you), 再見 (goodbye)
- **Numbers**: 一 (one) to 十 (ten)
- **Colors**: 紅色 (red), 藍色 (blue), 黃色 (yellow)
- **Family**: 爸爸 (father), 媽媽 (mother), 哥哥 (brother)
- **Food**: 飯 (rice), 水 (water), 茶 (tea)
- **Verbs**: 食 (eat), 飲 (drink), 行 (walk)
- **Adjectives**: 好 (good), 靚 (beautiful), 大 (big)
- **Time**: 今日 (today), 聽日 (tomorrow), 而家 (now)

## Technical Details

- **Pure JavaScript**: No external game libraries required
- **HTML5 Canvas**: Smooth 2D graphics rendering
- **Web Speech API**: Browser-based Cantonese pronunciation
- **Responsive Design**: Works on different screen sizes

## Browser Compatibility

Best experienced on:
- Google Chrome (recommended for best TTS support)
- Mozilla Firefox
- Safari
- Microsoft Edge

Note: Text-to-Speech quality for Cantonese may vary depending on your browser and operating system. Hong Kong or Taiwan Chinese voices work best.

## Learning Tips

1. Pay attention to the word display at the top showing the character you just hit
2. Click on words to hear them pronounced multiple times
3. Try to remember the Jyutping romanization to improve pronunciation
4. The more you play, the more vocabulary you'll encounter and retain!
